## What This Skill Does

**`/debug-and-fix-bugs`** transforms debugging from guesswork into a disciplined engineering process:

| Phase | Name | Outcome |
|-------|------|---------|
| 0 | Confidence Gate | ≥96% clarity before planning |
| 1 | Architectural Analysis | Control/data flow map + evidence-based findings |
| 2 | Debugging Assessment | Prioritized defect register with root causes |
| 3 | Production Refactoring | Surgical fixes with defensive patterns |
| 4 | Self Code Review | Hostile review of own changes |
| 5 | Verification & Simulation | Real stack execution + bug reproduction |
| 6 | Readiness Report | Production-readiness % + residual tracking |

## When to Use

Invoke `/debug-and-fix-bugs` when you need to:
- Fix intermittent bugs, race conditions, memory leaks
- Audit code for correctness, security, performance issues
- Refactor buggy algorithms/data structures with confidence
- Eliminate "works on my machine" problems
